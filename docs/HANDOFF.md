# Παράδοση: Finance Tracker

Ημερομηνία: 23 Οκτωβρίου 2026. Κλάδος: `build/finance-tracker` (μία δέσμευση ανά φάση, όλες στο origin).
Οι φάσεις 0–8 ολοκληρώθηκαν. Το `main` δεν έχει αλλάξει: τη συγχώνευση την κάνεις εσύ.

## Τι παραδίδεται

- **Εφαρμογή (PWA):** έσοδα (αναμενόμενα / εισπραγμένα), έξοδα, πάγια και συνδρομές, λογαριασμοί και μεταφορές,
  προϋπολογισμοί, ημερολόγιο επαναλαμβανόμενων, διαγράμματα, στόχοι αποταμίευσης, Έξυπνο πλάνο, μηνιαίες αναφορές,
  εκτίμηση φόρου και ΕΦΚΑ για ελεύθερο επαγγελματία, προαιρετική ενότητα επενδύσεων (κλειστή από προεπιλογή).
- **Ειδοποιήσεις (Web Push):** καθημερινή υπενθύμιση 21:00, ροή 1ης του μήνα 09:00, ανανεώσεις συνδρομών, υπερβάσεις
  προϋπολογισμού, αποτυχίες backup, προαιρετική σύνοψη αγοράς. Όλες στην ώρα Ελλάδας, χωρίς διπλές αποστολές.
- **Υποδομή:** Docker Compose (app, worker, mongo, backup), εφαρμογή μόνο σε `127.0.0.1`, MongoDB χωρίς ανοιχτή θύρα,
  πρόσβαση μόνο μέσω Tailscale. Κρυπτογραφημένα backup με restic (τοπικά ή στο δικό σου ιδιωτικό R2).
- **CI/CD:** CI με `ci-success`, Release προς GHCR μετά από merge στο `main`, σενάρια `deploy/` με pre-deploy backup,
  έλεγχο ετοιμότητας, αυτόματο rollback και κράτηση των 3 τελευταίων εικόνων.

## Τι κάνεις εσύ, με τη σειρά

1. **Έλεγξε και συγχώνευσε** το `build/finance-tracker` στο `main`. Μετά δες ότι το Release πέρασε και ότι τα δύο
   packages στο GHCR (`finance_tracker`, `finance_tracker-backup`) είναι ιδιωτικά.
2. **Προστασία του `main`** (αν το προσφέρει το πλάνο σου): απαίτησε τον έλεγχο `ci-success`.
3. **Server:** ακολούθησε στο `README.md` τις ενότητες «Server setup» και «Tailscale serve»: `.env`, `docker login`
   στο GHCR με classic token μόνο `read:packages`, `deploy/deploy.sh sha-xxxxxxx`, ενεργοποίηση MagicDNS και HTTPS
   στο Tailscale, `tailscale serve`. Ποτέ Funnel.
4. **Κράτα αντίγραφο του `RESTIC_PASSWORD`** στον password manager σου. Χωρίς αυτό δεν γίνεται επαναφορά.
5. **R2 (προαιρετικό αλλά συνιστάται):** νέο ιδιωτικό bucket μόνο για backup, χωρίς custom domain και χωρίς r2.dev,
   token Object Read & Write μόνο για αυτό το bucket, `BACKUP_TARGET=s3`, `backup-now`.
6. **Εγκατάσταση στο κινητό:** Κοινοποίηση → Προσθήκη στην οθόνη Αφετηρίας. Στο iPhone οι ειδοποιήσεις δουλεύουν μόνο
   στην εγκατεστημένη εφαρμογή (iOS 16.4+), και η άδεια ζητιέται από τις Ρυθμίσεις.
7. **Λογιστής:** δείξε του τη λίστα «Ανοιχτά ερωτήματα» στη σελίδα Φόρος & ΕΦΚΑ (και την ενότητα 10 του
   `docs/research/tax-efka.md`). Αν κάποια τιμή διαφέρει, διόρθωσέ την στους συντελεστές της σελίδας.
8. **Επενδύσεις (αν τις θέλεις):** άνοιξέ τες στις Ρυθμίσεις. Για τιμές από παρόχους βάλε δωρεάν κλειδιά στο `.env`
   και τρέξε τον έλεγχο της ενότητας 8 του `docs/MARKET-DATA.md`. Χωρίς κλειδιά, καταχωρίζεις τιμές με το χέρι.
9. **Αυτόματη ενημέρωση (προαιρετική):** `deploy/finance-updater.timer`, κλειστό μέχρι να το ενεργοποιήσεις.

## Τι δεν επαληθεύτηκε (λεπτομέρειες στο `docs/BLOCKERS.md`)

- Η πρώτη εκτέλεση του Release και τα packages στο GHCR: γίνονται μόνο μετά το δικό σου merge (B-009).
- Deploy στον server, `tailscale serve`, ACL και firewall: απαγορευόταν η πρόσβαση στον server (B-012).
- Backup στο R2: δεν υπήρχαν διαπιστευτήρια· ελέγχθηκε το τοπικό αποθετήριο (B-004).
- Ζωντανά δεδομένα αγοράς: δεν υπήρχαν κλειδιά· οι πάροχοι ελέγχθηκαν με προσομοιωμένες απαντήσεις (B-003).
- Κανόνες φόρου/ΕΦΚΑ με σήμανση [αβέβαιο]: εφαρμόζεται η συντηρητική ερμηνεία και φαίνονται στην οθόνη (B-005).
- Προστασία κλάδου σε δωρεάν ιδιωτικό repo: δεν επιβεβαιώθηκε ότι διατίθεται (B-006).
- MongoDB 7.0 λήγει στις 31/08/2027: οδηγίες αναβάθμισης στο B-010.
